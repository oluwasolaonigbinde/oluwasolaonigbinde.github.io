# oluwasolaonigbinde.github.io

Personal portfolio site, served via GitHub Pages from this repo's `main`
branch root.

Source/dev copy (with project docs and history) lives in
[`spec-driven-template`](https://github.com/oluwasolaonigbinde/spec-driven-template).
This repo holds the deployable build: `index.html` + `assets/`.

To update this site, edit the source repo and copy `index.html` +
`assets/` over here, or push directly to this repo if that's easier —
either way, GitHub Pages picks up changes automatically on push to `main`.
